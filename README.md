# cgm-absorber-requirements

What S/N and spectral resolving power does it take to **detect** a circumgalactic absorber, and to
**resolve** it into its velocity components?

This repository computes both requirements for twelve strong CGM transitions — H I λ1216, Mg II λ2796,
Si II λ1260, S II λ1260, C II λ1335, Si III λ1206, Si IV λ1403, C IV λ1548, N V λ1239, O VI λ1032,
Ne VIII λ770 and O VII λ21.6 — using atomic data from the
[Trident](https://github.com/trident-project/trident) line list.

*Work in progress — figures, interactive explainer and technical note are added in later commits.*
