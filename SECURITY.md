# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/tanmay-starslab/cgm-absorber-requirements/security/advisories/new),
not as a public issue. Include what you found, where (URL or file), and how to reproduce it.

You can expect an acknowledgement within a few days. Once a fix is live, the advisory is published with credit to you,
unless you prefer otherwise.

## Scope

- The site at https://galaxies.tanmaysingh.uk (a static site) and the code in this repository.
- The sightline API server (`server/`, deployed separately) and its chat backend.

Out of scope: third-party services the site loads from (Hugging Face, CDNs), denial-of-service testing, and social
engineering.

## Supported versions

Only the latest release and the live site are maintained.
